Each line: name, what it is (reference lineage), where it fits. Hex values and fonts in the original entries are anchors only; derive colour with the protocol in `SKILL.md`. ## Social carousel, 3:4 (8)

1. N 90% Specimen Journal: nature and culture, magazine authority. 2. N 95% Product Notebook: stickers and UI scraps from the product. 3. B 95% Index: rankings, lists, numeric conclusions. 4. B 90% Panorama Strip: several images joined into one continuous picture. 5. N 80% Daily Paper: launches, reviews, method posts. 6. B 85% Trading Cards: one item per card, collectible. 7. Q 90% Blank and Vertical: slow stories, one object. 8. N 95% Area Infographic: treemaps and waffle grids.

Carousel rules: one image says one thing; the cover carries one hook (a number, a conclusion or a contrast) and one hero visual in a short title; the second image says what this is; the last lands on the next step; neighbouring images change composition; a panorama subject straddles the seam (about two thirds left, one third right) while each image still stands alone. No links, QR codes or absolute claims ("terbaik", "nomor satu") inside the images.
