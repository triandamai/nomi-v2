Neutral surfaces, one accent, mono for anything a machine produced. Every value below is a token in this file, themed for dark and light.

One accent, under 10%
Mint marks the single thing to act on. Neutrals do the hierarchy.
02
Mono for machine output

03
Borders over shadows
Shadows only for things that truly float: menus, toasts, dialogs.
04
Honest states
Show the real tool and target. No fake progress. Cost always visible.
05
Mascots are identity, not decoration
One per agent, flat colour, used only where an agent is speaking or working.
